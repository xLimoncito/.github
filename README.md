# xLimoncito / .github

Perfil público y archivos de comunidad de [xLimoncito](https://github.com/xLimoncito).

Producto: [xlimoncito.com](https://xlimoncito.com)

| Archivo | Para qué |
|---|---|
| `profile/README.md` | Página de la organización en GitHub |
| `ROADMAP.md` | Qué está en producción y qué sigue |
| `CHANGELOG.md` | Cambios que ya salieron, con fecha |
| `CODE_OF_CONDUCT.md` | Normas de participación |
| `CONTRIBUTING.md` | Cómo proponer cambios |
| `SECURITY.md` | Cómo reportar vulnerabilidades |
| `SUPPORT.md` | A dónde escribir según el tema |
| `.github/ISSUE_TEMPLATE/` | Plantillas de issues |
| `.github/PULL_REQUEST_TEMPLATE.md` | Plantilla de pull requests |

Estos archivos en la raíz también sirven como default para el resto de los repositorios de la organización que no tengan los suyos.

## Mapa de la organización

| Repositorio | Visibilidad | Contenido |
|---|---|---|
| `.github` | Público | Perfil y comunidad |
| `brand` | Público | Logos e iconos |
| `app` | Privado | Webapp (Next.js, Supabase, Mercado Pago, Amplify) |

El código nuevo del producto entra en `app`. No abras un repositorio por cada función.
