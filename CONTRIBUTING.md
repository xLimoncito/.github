# Cómo contribuir

Gracias por querer mejorar Limoncito. Esta organización publica la marca y la documentación de la comunidad. El código de [xlimoncito.com](https://xlimoncito.com) está en el repositorio privado `app`.

## Qué podés proponer acá

- Correcciones del perfil, de este repositorio o de la guía de marca
- Ideas de producto, escritas sin datos de otras personas
- Errores visibles del sitio, si se pueden contar sin datos de cuenta ni de pago

## Qué va por mail

| Tema | Dónde |
|---|---|
| Cuenta, cobro, acceso o contenido pago | [soporte@xlimoncito.com](mailto:soporte@xlimoncito.com) |
| Vulnerabilidad | [soporte@xlimoncito.com](mailto:soporte@xlimoncito.com), siguiendo [SECURITY.md](./SECURITY.md) |
| Alianza o uso de marca fuera de lo permitido | [hola@xlimoncito.com](mailto:hola@xlimoncito.com) |

No abras un issue con mails, alias, comprobantes, tokens ni capturas que muestren datos de un usuario.

## Issues

Usá una plantilla. Si el reporte es de seguridad, el canal es el mail, no GitHub.

## Pull requests

1. Abrí un issue si el cambio no es un typo chico.
2. Hacé un fork del repositorio público (`.github` o `brand`).
3. Un branch por cambio.
4. El texto de cara al público va en español, con voseo, igual que el producto.
5. No incluyas secretos ni archivos generados.

Los pull requests al código de la webapp quedan para quien mantiene el repositorio privado.

## Conducta

Aplica el [código de conducta](./CODE_OF_CONDUCT.md).
